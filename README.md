# Normatec Pricing

เว็บตั้งราคาเช่าเครื่อง Normatec: ตั้งราคาตามระยะเวลา (30 นาที ถึง 2 ชั่วโมง) เทียบกับราคาอ้างอิงในตลาด ประมาณจำนวนลูกค้าเพื่อดูความคุ้ม และเปรียบเทียบหลายแบบเป็นคอลัมน์

- iPhone / iPad: เปิดใน Safari → แชร์ → เพิ่มไปยังหน้าจอโฮม
- Mac: Safari → File → Add to Dock
- ข้อมูลที่แก้เก็บในเครื่องที่ใช้งาน ย้ายเครื่องได้ด้วยปุ่ม สำรองข้อมูล / นำข้อมูลกลับ ท้ายหน้า
