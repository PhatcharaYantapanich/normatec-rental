# Normatec Rental Planner

แอปวางแผนธุรกิจให้เช่าเครื่อง Normatec (Air Compression): ตั้งราคา ใบราคาสำหรับลูกค้า รายชื่อสโมสร ต้นทุน และคืนทุน

- เปิดใช้: GitHub Pages ของ repo นี้
- iPhone / iPad: เปิดใน Safari → แชร์ → เพิ่มไปยังหน้าจอโฮม
- Mac: Safari → File → Add to Dock
- ข้อมูลที่แก้จะเก็บในเครื่องที่ใช้งาน ย้ายไปเครื่องอื่นได้จากหน้า ตั้งค่า → ส่งลิงก์ข้อมูล / ไฟล์สำรอง

ไฟล์ทั้งหมดเป็นเว็บแบบคงที่ (HTML + JS) ไม่มีเซิร์ฟเวอร์ ไม่เก็บข้อมูลผู้ใช้
